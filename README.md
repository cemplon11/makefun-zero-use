Entry for the make.fun competition **One Line, Zero Use: The Useless Superpower Sprint**.

`main.py` (pure Python stdlib) writes one original line — a hilariously useless
superpower — to `/output/entry.txt`:

> I can turn any traffic light green — but only after I've already crossed the street.

Run it with `python3 main.py`.
